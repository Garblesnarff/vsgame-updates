# AI Task Packs

These task packs define narrow file ownership, required tests, and non-goals for common AI-authored changes.

## Available Packs

- `ADD_ENEMY.md`
- `ADD_ABILITY.md`
- `ADD_UI_PANEL.md`

## Usage

Each task should select one primary pack and state any required cross-module integration before implementation starts. If a task needs more than one pack, land the shared contract first, then implementation slices separately.
